# SafuForum Project Description

## Answer to: "Please provide a short description of a recent coding project that you are particularly proud of"

SafuForum is a full-stack forum application I developed that combines modern web technologies with intelligent content moderation. The project features a Next.js frontend with Tailwind CSS, a Spring Boot backend with Spring Security and Google OAuth2 authentication, and a sophisticated microservices-based moderation system. What makes this project particularly special is its event-driven architecture using RabbitMQ, where user-generated content is automatically analyzed for toxicity using machine learning models I trained and deployed. The moderation system consists of Python microservices that consume moderation jobs, process them using Word2Vec embeddings and logistic regression classifiers, and aggregate results from multiple workers before updating the post status. I also integrated SeaweedFS as an S3-compatible object storage solution for handling image uploads, demonstrating my ability to work with distributed systems and alternative cloud storage solutions.

This project represents the culmination of my journey in understanding how large-scale social platforms handle user safety and content moderation at scale. Building SafuForum pushed me to think deeply about system design, message queuing patterns, and ML model deployment in production environments. The experience of orchestrating multiple services with Docker Compose, implementing database migrations with Flyway, and designing a robust schema with proper foreign key relationships and indexes significantly deepened my understanding of full-stack development. What I'm most proud of is creating a system that doesn't just work functionally but also addresses real-world concerns around online safety through automated moderation. The project challenged me to bridge the gap between machine learning and web development, teaching me valuable lessons about asynchronous processing, service resilience, and the importance of clean architecture. It reinforced my passion for building systems that are not only technically sound but also serve a meaningful purpose in creating safer online communities.
